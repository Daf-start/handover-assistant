# Handover Assistant User Guide

## Login
Use Microsoft Entra ID to access the application. Permissions are granted based on your role.

## Main workflow
1. Open the Dashboard.
2. Create or open a handover expediente.
3. Import Outlook emails.
4. Validate AI-generated suggestions.
5. Track tasks and documents.
6. Generate final report.

## FAQs
### How are AI suggestions handled?
AI suggestions are shown as pending recommendations. The user confirms before updating the official record.

### Can I share the app?
Yes, the app can be deployed to a Linux server and accessed by authorized users through the web interface.
